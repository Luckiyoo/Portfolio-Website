# Portfolio Website - Jun Howell Mifa Abucay

A modern, responsive portfolio website built with React and Tailwind CSS.

## Features

- ✨ Modern, clean design
- 📱 Fully responsive (works in portrait and landscape)
- ⚡ Fast and optimized with Vite
- 🎨 Beautiful UI with Tailwind CSS
- 🌐 Smooth scrolling navigation
- 💼 Skills showcase
- 🚀 Project portfolio
- 📧 Contact form

## Getting Started

### Installation

```bash
npm install
```

If you cloned from GitHub (or deleted `node_modules` to reduce size), run the command above inside the `portfolio` folder to reinstall dependencies before starting the dev server.

### Run Development Server

```bash
npm run dev
```

The site will open at `http://localhost:3000`

### Build for Production

```bash
npm run build
```

Tip: You can also use `START_PORTFOLIO.bat` (Windows). It auto-installs dependencies if `node_modules` is missing and then starts the server.

## Customization

Edit the following files to customize your portfolio:
- Update your name in the components (already set to Jun Howell Mifa Abucay)
- Add your projects in `src/components/Projects.jsx`
- Update skills in `src/components/Skills.jsx`
- Modify contact information in `src/components/Contact.jsx`
